# Eventos Climáticos Back end

## Objetivo:

 Conectar o back-end da aplicação web com um banco de dados relacional, utilizando o SGBD MariaDB e a linguagem de programação JavaScript com Node.js.

## Tecnologias usadas: 
- Node.js
- JavaScript 
- Vs Code

## Atividade: 

* Fazer um código atualizar e excluir para o evento e usuários.
* Fazer rota getde resumo e rota postde login.
